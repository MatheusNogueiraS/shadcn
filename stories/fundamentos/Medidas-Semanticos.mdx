# Semânticos

Os semânticos dão nome às medidas: raio para os cantos, padding para o espaço interno, gap para a distância entre elementos, size para largura e altura iguais, stroke para a espessura dos contornos e sombra para a elevação. Os componentes usam **somente estes nomes**.

Para mudar uma medida, edite os arquivos em `tokens/` e rode `pnpm tokens`.

## Size

Largura e altura iguais, em ícones, avatares, checkbox e botões só com ícone. Os botões só com ícone têm a mesma medida da altura do botão com texto, que usa a escala do Tailwind: `size-(--size-3xl)` e `h-9` valem 36 px. Ao mudar um, confira o outro.

## Stroke

Como nas cores, um `stroke` vale para qualquer contorno, e a classe diz onde ele é aplicado: `stroke-sm` é usado como `border-sm`, `ring-sm`, `outline-sm` ou em um lado só, como `border-b-sm`.

## Sombra

As sombras vão da mais fraca, `shadow-sm`, à mais forte, `shadow-xl`. Para escolher a força, troque a classe, que tem o nome do token: `shadow-lg`. As outras sombras do Tailwind, como `shadow-2xl`, não existem neste projeto.

Todas usam a mesma cor, `shadow-color`, que fica em Cores/Semânticos. No Figma, cada sombra é um estilo de efeito com o mesmo nome. A posição, o desfoque e a expansão ficam como número, porque uma expansão negativa não se liga a uma variável.

## Tailwind

Os tokens acima são a base para construir componentes, aqui e no Figma. Além deles, os componentes usam outras classes do Tailwind, do jeito que o shadcn as escreveu: alturas como `h-9`, larguras como `min-w-32` e `max-w-sm`, posições como `top-3.5`, deslocamentos como `-translate-y-1/2`, valores escritos na classe, como `pr-[4.5rem]`, e o zero, como `p-0`, `gap-0`, `border-0` e `rounded-none`. Elas ficam como estão para preservar o comportamento do shadcn e não têm variável no Figma.

No Tailwind, o número da classe vezes 4 dá o valor em px: `h-9` vale 36 px. Se um componente novo pedir uma medida que se repete, ela pode virar token e entrar nas tabelas acima.

## Regras de uso

- **Por que não `p-sm`.** O nome seria mais curto, mas uma variável `--spacing-sm` faz `max-w-sm` passar a valer 8 px em todo o sistema.
- **Margens usam os tokens de gap.** Por exemplo, `-mx-(--gap-xs)` e `mt-(--gap-sm)`. Quando a margem desfaz um padding, ela usa o token desse padding.
